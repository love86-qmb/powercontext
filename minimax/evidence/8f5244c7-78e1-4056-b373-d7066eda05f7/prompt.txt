# Stable repository identity

The SDD task ledger must use one stable key for the same checkout spelling on
Windows or POSIX. `canonical_repository_key(value)` is governed by these rules:

1. Reject an empty or whitespace-only value with `ValueError`.
2. Convert backslashes to forward slashes.
3. Collapse repeated separators, except that a leading UNC `//` remains `//`.
4. Remove trailing separators unless the value is `/` or a drive root such as `c:/`.
5. Normalize an ASCII Windows drive letter and all other ASCII path letters to lowercase.
6. Do not access the filesystem. The result depends only on the supplied text.

Examples:

- `C:\\Work\\PowerContext\\` → `c:/work/powercontext`
- `c:/work//powercontext` → `c:/work/powercontext`
- `//SERVER/Share/Repo/` → `//server/share/repo`
- `/srv/PowerContext/` → `/srv/powercontext`

The immutable regression tests define the accepted boundary behavior.

from __future__ import annotations

import unittest

from minimax.sdd_context.task_identity import canonical_repository_key


class RepositoryIdentityTest(unittest.TestCase):
    def test_windows_and_posix_spellings_share_one_key(self) -> None:
        self.assertEqual(canonical_repository_key("C:\\Work\\PowerContext\\"), "c:/work/powercontext")
        self.assertEqual(canonical_repository_key("c:/work//powercontext"), "c:/work/powercontext")

    def test_unc_prefix_is_preserved(self) -> None:
        self.assertEqual(canonical_repository_key("\\\\SERVER\\Share\\Repo\\"), "//server/share/repo")

    def test_posix_path_is_normalized_without_filesystem_access(self) -> None:
        self.assertEqual(canonical_repository_key("/srv/PowerContext/"), "/srv/powercontext")
        self.assertEqual(canonical_repository_key("/"), "/")

    def test_empty_value_is_rejected(self) -> None:
        with self.assertRaises(ValueError):
            canonical_repository_key("  ")


if __name__ == "__main__":
    unittest.main()
